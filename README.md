# 🛡️ DeepShield Forensic Engine

Advanced AI-powered deepfake detection system for images, audio, and video.

## 🚀 Features

- **Multi-modal Detection**: Analyze images, audio, and video for deepfake indicators
- **Real AI Models**: Uses state-of-the-art deep learning models
- **Ensemble Approach**: Combines multiple detection methods for higher accuracy
- **Real-time Analysis**: WebSocket support for live updates
- **Comprehensive Reports**: Detailed analysis with visual heatmaps and spectrograms
- **Batch Processing**: Analyze multiple files simultaneously
- **RESTful API**: Easy integration with other applications
- **Docker Support**: Containerized deployment
- **Database Storage**: SQLite for storing analysis history
- **Statistics Dashboard**: Track detection metrics over time

## 📋 Prerequisites

- Python 3.8+
- Node.js (for frontend development)
- Docker (optional)
- 4GB+ RAM (8GB recommended for video analysis)
